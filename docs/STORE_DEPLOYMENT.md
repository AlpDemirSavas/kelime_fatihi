# Store deployment

V7 için ayrıntılı, sıfırdan yayın rehberi:

**`docs/YAYIN_REHBERI_TR.md`**

Kısa kritik notlar:

- App Store yüklemesi için macOS + güncel Xcode gerekir.
- 23 Temmuz 2026 itibarıyla App Store Connect yüklemeleri Xcode 26+ / iOS 26 SDK ile hazırlanmalıdır.
- Google Play'de 31 Ağustos 2026'dan itibaren yeni mobil uygulama/güncellemeler API 36+ hedeflemelidir; projeyi şimdiden API 36'ya hazırlayın.
- `com.example.kelime_fatihi` canlı paket kimliği olarak kullanılmamalıdır.
- Firebase, AdMob, IAP, banka/vergi ve privacy URL değerleri hesap sahibinin gerçek bilgileriyle tamamlanmalıdır.
